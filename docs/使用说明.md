# 玩具操作视频粗剪 Skill

安装包中的 `toy-demo-roughcut` 是完整技能：团队风格、8组学习依据、观察工具和本地渲染脚本都在里面。无需安装OpenStoryline、VectCutAPI或剪映，也不用额外模型API Key；需要能使用Codex的账号。画面分析在Codex会话中进行，不是完全离线。

## 安装到同事电脑

### 方法一 让Codex精确定位并安装

复制下面整段到Codex，无需先手动下载或填写本机目录：

```text
请在GitHub精确定位并核对这个项目，然后下载并安装为我的个人技能：
仓库：https://github.com/x2185/toy-demo-roughcut
所有者：x2185
仓库名：toy-demo-roughcut
分支：main
技能子目录：toy-demo-roughcut

请核对所有者、仓库名及该子目录的SKILL.md，避免下载同名项目。
安装完整技能目录，并检查Python、FFmpeg、ffprobe和Pillow依赖。
如果已安装，请先备份再更新，保留local-memory-location.txt和本机记忆。
```

提供准确链接即可定位，不必依赖搜索排名或模糊关键词。Codex可使用GitHub技能安装工具下载；网络或目录权限受限时，按应用提示授权。每台电脑安装一次，下次直接调用技能。

### 方法二 从GitHub手动下载

1. 打开 https://github.com/x2185/toy-demo-roughcut 。仓库已公开，浏览和下载ZIP无需协作者权限。
2. 点击绿色 **Code → Download ZIP**，下载后完整解压，不需要安装Git。打开解压目录，应能看到 `toy-demo-roughcut`、`docs` 和安装脚本；Word手册在docs文件夹中。在Codex里发送：“把这个目录里的 toy-demo-roughcut 安装为我的个人 Skill：解压目录完整路径。”例如 `D:\下载\toy-demo-roughcut-main`，须换成自己电脑的实际路径。不要只粘贴SKILL.md，scripts和references也要保留。
3. Windows也可在PowerShell运行同包的 `安装到Codex.ps1`。它只复制到当前用户的 `.codex/skills/toy-demo-roughcut`，不会覆盖已有同名技能。安装后在下一轮对话检查是否已发现；未发现时重开Codex。
4. 让Codex检查Python3.10+、ffmpeg/ffprobe；只有联系表需要Pillow，缺少时安装。FFmpeg必须包含libx264及HDR转换所需滤镜；需要HDR输出另需libx265。安装包未捆绑Python、FFmpeg或账号。

## 平时怎么用

直接给完整路径：

> 使用 $toy-demo-roughcut 粗剪 D:\素材\玩具.mp4，按团队风格，保留所有款式及关键操作、原声和原生分辨率，成片另存。

可补充“全程原速”“尽量30秒但不丢步骤”“先给删除建议再剪”。不给额外要求时，按技能默认流程先观察、作出源时间剪辑清单，再生成首版；不会额外强制逐次确认。

## 默认结果

- 原生分辨率（4K源输出4K），保持原构图与展示顺序；不加字幕、配乐、音效或复杂转场。
- 删除无关取放、等待、同义重试；必要装入、连接、释放及结果保留，难判断则保守处理。
- 不强制所有成片30秒，不统一加速。真实弹射/回弹等关键物理动作优先原速。
- 默认4K BT.709 SDR，与本批人工成片相符；用户要求保留HDR时另选HLG/PQ模式，杜比视界动态元数据不保留。4K与HDR是两件事。
- 输出MP4及同名`.edit.json`，不覆盖源素材或已有输出。查看成片提出“这段多留一点”“不要加速”等即可继续迭代。

## 实际边界

这是基于8组样例的经验和执行工具，不是专用训练模型。首次让同事复核少量视频，尤其小零件、快速动作、所有款式是否齐全及声音听感。脚本检查通过并不等于剪辑风格已获认可。

详细学习依据在 `toy-demo-roughcut/references/eight-pairs.md`。原始16条视频和研究用低分辨率帧不包含在安装包中，技能不依赖它们才能执行。

## 本次补充的复核方式

剪前逐款、逐操作核对覆盖，剪后逐个检查拼接处，避免漏款、装配突然完成或回弹结果被剪断。不能看清的动作会保守处理并说明。反馈时给出成片版本和时间，例如“第二版第8秒松手太快，多保留回弹”；Codex据此定位原素材并修改。单条视频的修改不会自动变成所有视频的规则。

升级已有技能时，重新从GitHub的Code → Download ZIP下载并解压最新版，把实际解压目录交给Codex，说明“备份现有版本后，用这个版本更新toy-demo-roughcut，保留local-memory-location.txt及本机记忆”。仓库更新不会自动更新电脑里已安装的技能。同包安装脚本仍仅用于首次安装，遇到同名目录会停止，避免覆盖同事自行积累的偏好。

第二轮样片精看还补充了动作内部的省略剪辑：已交代关系的取出、换手、反复装入对位可以跳过；新款辨识和关键效果仍保留。第一款可以承担共用包装/玩法介绍，各款不必等长。具体成片切点证据见 `toy-demo-roughcut/references/cut-techniques.md`，不是要求所有操作都剪成一镜到底。

## 本机积累经验

默认由Codex在当前剪辑任务内完成分类、复盘和本机记录，不要求用户填写表格或逐条确认学习结果。直接给素材、要求和修改意见即可。明确长期要求保存为偏好，其他有价值反馈保存为条件化经验，证据不足的经验不自动推广。这里的后台处理不是任务结束后持续运行的程序。

每次调用技能时，Codex按 `references/local-memory.md` 读取本机偏好。说“这条以后都这样，记住”可以保存长期习惯；“仅这条改一下”只针对本片。长期规则更新前保存旧版本，可要求撤销。记录在技能目录之外，升级时保留，不自动共享给同事。安装包只有通用机制，没有原作者的本机偏好、反馈或路径配置。

本机文件保存不代表离线分析：读取的偏好会进入当前Codex会话上下文。此机制不后台运行，也不保证未调用技能的对话会读取记录。

## 新类型玩具

可以直接提供其他玩具实拍素材，无需先归到捏捏、磁吸或弹弓。技能会根据展示目的、操作步骤和实际结果判断，声光、延迟变化、连续运动、变形装配等各自核查。不固定30秒、统一倍速或固定停留；技术参数按新素材读取。已有8组是参考案例，新类型的实际剪辑效果仍需用新素材复核。

## 调用时检查更新

升级到带 `release.json` 的版本后，每个新对话首次调用技能时，Codex按技能指令检查GitHub上游。有新版会先暂存、核对文件及本地差异、备份后更新；本机经验和配置保留。网络失败继续用本地版，有自行修改冲突则保留本地并提示。此流程由Codex执行，仍受网络、工具和目录权限限制，不是常驻后台程序。

已经安装旧版的同事需要先主动升级一次：

```text
请从 https://github.com/x2185/toy-demo-roughcut
更新本机 toy-demo-roughcut 到带release.json的最新版。
先完整备份旧技能，保留本机路径配置和所有经验记录。
```

发布者后续修改技能时须同步更新release.json的版本及文件哈希，才能可靠检测。具体流程见技能内references/updates.md。
