# 安装后的入门提示

首次安装完成时由安装方Codex读取本页，按实际安装和依赖检查结果说明。不要把“复制完成”说成所有运行依赖均可用。此文件不是会自动弹窗的安装钩子，需Codex读到并执行。

使用实际执行剪辑的Python运行 `scripts/check_environment.py`，说明普通SDR、HDR转SDR、HDR输出中哪些可用；缺少某项不自动安装全套工具。有素材时按其色彩模式解决必要缺项，再继续任务。

用简短回复主动包含以下内容，不要求用户填写表格或逐项回答：

- 给一条能直接复制的调用示例：`使用 $toy-demo-roughcut 粗剪 D:\素材\玩具.mp4，保留关键操作、原声和原生分辨率，成片另存。` 路径须换成用户本机实际文件。
- 素材放固定目录，每个产品单独归放，避免使用容易清理的聊天缓存；保留原片。
- 有特别要求只需补充必须保留的玩法、重点效果、原速等；分类、剪辑清单和复盘由Codex处理。
- 首版检查有无漏款/漏玩法、过程是否看得懂、关键效果是否剪断或变速失真；首次建议用一两条简单素材试用。
- 修改时说版本和成片时间，例如“第二版第8秒多留一点回弹”；MP4与同名.edit.json一起保存便于修改。
- 个人经验留在本机。新版会按流程在新对话首次调用时尝试检查更新，联网/权限失败仍可继续本地版；不承诺常驻运行。

提示后，在按local-memory.md定位的记忆目录写入onboarding.json，保存提示日期及技能版本；该标记是本机文件，不上传。记录失败不阻塞剪辑；同一对话不反复提示，用户要求重新介绍时可再讲。已有onboarding.json则不主动重复，新版升级只说明影响使用的重要变化。

如用户已有视频路径，简要说明调用与检查方式后直接开始，不停下来等待“是否开始”。新技能未被发现时说明下一轮尝试，仍不识别再重开Codex。
